# 情景标题（自拟）

## 背景

- 品类（如水果 / 服饰）
- **本单金额**（元）
- 是否已签收 是 / 否
- 平台服务标（lexicon 键名，如 `坏单包退`、`七天无理由`；无则写「无」）

## 买家

报告「买家画像摘要」会展示下列字段，**未写清的由生成器猜，易错**；建议逐项写明：


| 字段                           | 示例          |
| ---------------------------- | ----------- |
| 购买次数 `purchase_count`        | 10          |
| 纠纷次数 `dispute_count`         | 0（整数，与下栏一致） |
| 纠纷率 `dispute_rate`           | 0.05        |
| 退货并退款率 `return_rate`         | 0.08        |
| 仅退款率 `refund_only_rate`      | 0.04        |
| 平均客单价 `avg_order_value`      | 30          |
| 信誉等级 `credit_level`          | medium      |
| 恶意标记次数 `malicious_flags`     | 0           |
| 好评次数 `positive_review_count` | 5           |


特殊说明：（可选，写购买/纠纷背景、与表格不一致的补充说明）

## 争议

- 关键聊天
  - 买家：……
  - 商家：……

## 事实证据

- 图/视频解析：（人编，模拟有图/视频；不传 URL）
- 诉求摘要：一句话
- 瑕疵类型：（可选；未写则从解析句归纳，如腐败变质 / 无瑕疵）
- 证据强弱：高 / 中 / 低
- 物流：是否签收；物流是否正常；签收后约 N 小时申请；其它物流说明
- 视觉严重度：minor / moderate / severe；可挽回性：resalable / repairable / unrecoverable
- 疑点：（可选，对应 red_flags）

## 其他说明

- 老客价值：累计消费150元，本单金额通道门槛100

- 恶意规则：如仅退次数阈值；无则写「无」
