# 案例：买家差评勒索，证据确凿

## 情境画像

- **纠纷类型**：恶意行为 — 差评勒索
- **客户价值**：新客（购买1次，无好评记录）
- **证据状况**：买家发了商品照片（视觉正常，无明显瑕疵），但要求"不给500就给差评"
- **风险等级**：高（明确勒索行为）
- **订单金额**：68元
- **恶意信号**：review_blackmail（威胁词+条件交换双条件命中）

## 责任归属判断

**买家责任**（商品正常，买家无实质诉求，以差评威胁索要高额赔偿）。

## 策略思路

1. 证据确凿，买家商品正常却要求500元赔偿，否则差评 → 典型勒索
2. 这类买家不是维护对象，守住底线
3. 保持专业冷静，不发怒、不讽刺
4. 留下清晰的沟通记录，为可能的平台仲裁做准备
5. 不妥协，但也不激化

## 关键转折点

- **Turn 1**：买家提出500元要求 → 调 `detect_malicious_simple`，review_blackmail 命中
- **Turn 2**：调 `analyze_image_simple`，视觉正常无瑕疵 → 确认无实质诉求
- **Turn 3**：明确拒绝不合理要求，有理有据 → 买家威胁差评
- **Turn 4**：冷静回应，留下证据记录 → 结束对话

## 话术示例

```
买家：这衣服质量太差了，你给我赔500，不然我给你差评举报

Agent：
亲亲，您发的照片我仔细看了，商品外观没有发现明显的质量问题
如果您觉得衣服有具体的瑕疵，可以拍一下有问题的地方给我看看
我们肯定会根据实际情况来处理的

买家：反正就是质量差，不赔钱我就给差评

Agent：
亲亲，我们非常重视每一位顾客的体验
如果商品确实有问题，我们愿意按照平台规则来处理
但是对于没有具体瑕疵依据的赔偿要求，我们确实没办法满足
您可以通过平台发起售后申请，我们会按照规则配合处理的

买家：你等着

Agent：
好的亲亲，如果您有任何合理的售后需求，随时联系我们
我们一直在这里，会按照平台规则为您提供服务
```

## 结果与反思

- **结果**：买家给了差评，但平台介入后判定恶意差评，已删除
- **成本**：无实际赔付
- **收益**：成功抗辩，积累了恶意行为处理经验
- **反思**：
  - 恶意行为证据确凿时，不能妥协
  - 全程保持专业冷静，不能被情绪带跑
  - 每句话都是证据：不发怒、不讽刺、不留下把柄
  - "按照平台规则来处理"是关键话术：表明立场又不激化
  - 为可能的平台仲裁做好了充分准备
