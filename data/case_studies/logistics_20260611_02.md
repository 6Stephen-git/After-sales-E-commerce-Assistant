# 案例：物流停滞超时，买家情绪激动

## 情境画像

- **纠纷类型**：物流异常 — 快递停滞5天未更新
- **客户价值**：普通新客（购买2次，无纠纷记录）
- **证据状况**：物流信息确认停滞，买家无额外举证
- **风险等级**：中（买家情绪激动，提到了"投诉"）
- **订单金额**：89元

## 责任归属判断

**责任不清**（物流停滞可能是快递公司问题，非直接商责，但商家有义务协调解决）。

## 策略思路

1. 买家情绪激动，先安抚再处理
2. 物流问题商家有协调义务，不能甩锅给快递
3. 先查物流状态确认事实，再给方案
4. 新客也要妥善处理，不能因为"不重要"就敷衍
5. 物流停滞 → 优先方案：催物流+承诺时效，超时则退款

## 关键转折点

- **Turn 1**：买家投诉物流停滞，情绪激动 → 先安抚，表达理解
- **Turn 2**：调 `query_logistics` 确认停滞5天 → 事实清晰
- **Turn 3**：给出方案：先催物流，24小时内无更新直接退款 → 买家接受
- **Turn 4**：次日物流仍停滞 → 主动退款+表达歉意

## 话术示例

```
买家：快递都5天了还没动，你们发的什么垃圾快递，我要投诉

Agent：

物流那边确实好几天没更新了，我马上联系快递公司催一下
您放心，24小时内物流还没动静的话，我直接给您退款
这事儿我来处理，有消息我第一时间回复您

买家：那行吧，尽快

Agent：
好的亲亲，我已经催了，最迟明天这个时候给您回复
真不好意思了，给您添麻烦了

[次日物流仍停滞]

Agent：
亲亲，物流那边还是没动静，我不让您再等了

真的不好意思了哥，这单让您体验不好了

```

## 结果与反思

- **结果**：全额退款89元，买家未投诉
- **成本**：89元退款
- **收益**：避免了投诉升级，买家虽然不太满意但没有恶化
- **反思**：
  - 物流问题商家不能甩锅，要有担当
  - 先安抚情绪，再查事实，最后给方案
  - 说到做到：承诺24小时就24小时，到了就退款，不要拖
  - 新客也要好好处理，每一个买家都可能是老客的起点
