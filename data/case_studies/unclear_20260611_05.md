# 案例：买家称收货破损，无开箱视频

## 情境画像

- **纠纷类型**：商品质量 — 买家称收到破损，无开箱视频
- **客户价值**：普通客户（购买3次，无纠纷记录）
- **证据状况**：买家发了破损照片（视觉判定 moderate），但无开箱视频，签收已超48小时
- **风险等级**：中（证据链不完整）
- **订单金额**：198元

## 责任归属判断

**责任不清**（买家有破损照片但无开箱视频，无法确认是在运输中损坏还是签收后损坏）。

## 策略思路

1. 责任不清时，先补证再定策略
2. 买家照片显示 moderate 破损，有一定可信度
3. 但无开箱视频，签收已超48小时，证据链有缺口
4. 先温和地要求补证（快递面单、外包装照片），不要一上来就拒绝
5. 如果买家确实无法提供，再根据情况决定：老客可适当照顾，新客按规则处理

## 关键转折点

- **Turn 1**：买家投诉破损 → 先安抚，调 `analyze_image_simple`
- **Turn 2**：视觉 moderate，但无开箱视频 → 决定先补证
- **Turn 3**：温和请求补拍外包装和快递面单 → 买家配合
- **Turn 4**：外包装无异常，证据链仍有缺口 → 给出折中方案

```

那亲亲方便拍一下商品破损的地方的近照吗
多角度拍几张，我这边好帮您核实

买家：[发了更多照片]

Agent：

虽然没法完全确认是哪个环节的问题，但商品确实有损坏

您看行吗
```

## 结果与反思

- **结果**：折中退99元（订单金额的50%），买家接受
- **成本**：99元退款
- **收益**：避免了纠纷升级，买家虽然不是完全满意但接受了方案
- **反思**：
  - 责任不清时，先补证再定策略
  - 补证要温和，不要让买家觉得你在刁难他
  - 如果买家确实无法提供完整证据，折中方案是合理的
  - "各承担一半"是一种公平的处理方式，买家通常能接受
  - 全程保持"在帮你解决问题"的态度，而不是"你在为难我"
