# 案例：衣服线头/色差，高价值老客

## 情境画像

- **纠纷类型**：商品质量 — 衣服有线头，轻微色差
- **客户价值**：高价值老客（购买15次，好评3条，累计消费2000+）
- **证据状况**：买家发了实物照片（视觉判定 minor，可二次销售）
- **风险等级**：低
- **订单金额**：259元

## 责任归属判断

**混合**（线头和色差属轻微瑕疵，可能是商品本身问题，也可能涉及买家主观预期；视觉判定 minor）。

## 策略思路

1. 老客高价值，保关系优先
2. 问题轻微（minor），商品可二次销售（resalable），不值得为这点小事伤关系
3. 但也不能无底线让步，适当补偿即可
4. 补偿在 max_compensation 范围内，给个小额补偿+表达诚意
5. 引导好评，将小瑕疵转化为服务加分

## 关键转折点

- **Turn 1**：买家反映线头和色差 → 调 `analyze_image_simple`，确认 minor
- **Turn 2**：查画像确认老客 → 决定适当补偿
- **Turn 3**：提出补偿方案（20元红包）→ 买家接受
- **Turn 4**：引导好评 → 成功

## 话术示例

```
买家：衣服线头好多啊，颜色跟图片也不太一样

Agent：
亲亲不好意思了，让您收到的衣服有瑕疵
我看了您拍的照片，确实有几个线头，颜色也跟图片有点出入
这个是我们发货前检查没做到位，给您添麻烦了
这样吧，我给您发个20元红包作为补偿，您看行吗

买家：行吧

Agent：
好嘞，红包马上发您
线头的话您用剪刀稍微处理一下就好了，不影响穿着的
亲亲对处理和商品满意的话，可以留个带图好评吗
谢谢您啦，下次有需要再光临小店啊！
```

## 结果与反思

- **结果**：补偿20元红包，买家留了好评
- **成本**：20元红包
- **收益**：老客留存+好评（老客长期价值2000+，20元换好评和关系，非常划算）
- **反思**：
  - 轻微瑕疵不要小题大做，也不要完全不理
  - 老客关系比单次利润重要得多
  - 20元补偿换老客的好感和好评，投入产出比很高
  - 但要注意：如果问题严重（severe），补偿策略要相应调整
