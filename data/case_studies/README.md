# 案例库说明

## 案例结构

每条案例包含以下字段：

- **情境画像**：纠纷类型、客户价值、证据状况、风险等级
- **责任归属判断**：商责/买家责任/责任不清/混合
- **策略思路**：为什么这么做（不是做了什么）
- **关键转折点**：哪个节点做了什么决策
- **话术示例**：体现人情世故
- **结果与反思**：最终结果和经验教训

## 案例来源

- MVP 阶段：手工预置 3-5 个典型案例
- 后续：Agent5 复盘后自动写入，格式对齐上述结构

## 文件格式

每个案例一个文件，文件名格式：`{类型}_{日期}_{序号}.md`
