# 案例：三文鱼坏单包退（老客、超24小时）

## 情境画像

- **纠纷类型**：食品质量问题 — 三文鱼坏单
- **客户价值**：高价值老客（购买20+次，好评5+条，累计消费3000+）
- **证据状况**：买家发了商品照片（鱼肉松散偏暗，视觉判定 moderate），无开箱视频
- **风险等级**：低（老客、问题清晰）
- **订单金额**：158元
- **特殊条件**：签收超24小时，买家有「坏单包退」服务标

## 责任归属判断

**商责**（产品确实存在质量问题，视觉证据支持买家诉求）。

## 策略思路

1. 买家是高价值老客，长期消费贡献大，保客优先于保本单利润
2. 视觉证据已确认问题，再拖只会激化矛盾
3. 老客+商责+证据清晰 → 直接善后，主动承担，不扯皮
4. 善后时争取好评，将坏事变好事

## 关键转折点

- **Turn 1**：买家发图投诉 → 立即调 `analyze_image_simple`，确认视觉判定 moderate
- **Turn 2**：查买家画像，确认老客高价值 → 决定直接善后，不走繁琐流程
- **Turn 3**：主动提出全额退款+代金券 → 买家态度缓和
- **Turn 4**：引导好评，表达感谢 → 买家同意

## 话术示例

```
买家：收到的三文鱼都臭了，肉都是散的

Agent：
亲亲真不好意思了，让您收到这样的商品，确实是我们这边的问题
您拍的照片我看了，鱼肉状态确实不对，这单我来帮您搞定
我这边直接给您安排全额退款，另外再送您一张20元代金券
下次您来小店再试试，我跟仓库那边也说一声，给您发最新鲜的

买家：行吧，退款多久到账

Agent：
退款我这边马上操作，一般1-3个工作日就到啦
亲亲对处理和商品满意的话，可以留个带图好评吗
谢谢您啦，下次有需要再光临小店啊！

买家：好的

Agent：
感谢您的体谅，希望您能再给小店一次机会！

```

## 结果与反思

- **结果**：全额退款+20元代金券，买家留了带图好评
- **成本**：158元退款+20元代金券 = 178元
- **收益**：老客留存+带图好评（口碑价值远超178元）
- **反思**：老客+商责，拖不如快。主动善后、态度好、加点补偿，坏事变好事。如果为了158元跟老客扯皮，损失的不只是这个客户，还有他背后可能带来的复购和推荐。
