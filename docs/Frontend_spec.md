# 前端界面规范

## 框架

Vue 3 ,Vite 构建，Axios 处理 HTTP 请求。

## 布局模式

- **辅助模式**：左右分栏。左侧聊天窗口，右侧 AI 策略面板。商家手动点击按钮触发分析，话术选项可点击填入聊天框。
- **智能模式（预留）**：仪表盘布局，展示对话状态、当前策略，商家可随时点击接管按钮切回辅助模式。

## 通信

- 辅助模式使用 HTTP REST，与后端 API 交互。
- 智能模式（预留）使用 WebSocket 接收实时消息推送。
- 前端不直接调用任何 Agent 函数，所有数据通过 API 获取。

## 枚举映射

- 前端负责将内部英文枚举值映射为中文展示：`defend → 抗辩`、`high → 高` 等。
- 映射逻辑集中在一个文件或模块，不散落各组件。

## 硬约束

- 商家始终掌握消息发送权（辅助模式下）。
- 情绪预警以非阻断式提示展示，不弹模态框打断商家操作。
- 模式切换按钮在设置页，切换时调用配置更新 API。
