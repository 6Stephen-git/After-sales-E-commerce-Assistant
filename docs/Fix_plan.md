# 修改计划

## Agent 2 & Agent 3 升级总计划表

依据 `Supplementary Design.md`、`agent2 upgrade.md`、`agent3 upgrade.md` 拆解。按模块单独立项做 plan 后再实施。

### Agent 2 升级模块

| # | 模块名称 | 核心改动 | 依赖 |
|---|---------|---------|------|
| **A2-1** | **客户价值评估 Tool** | 新建独立工具：长期价值分 + 本单价值分双维评分，分档逻辑，触发标记输出 | 无 |
| **A2-2** | **恶意行为检测 Tool（硬规则层）** | 新建工具第一层：7 项硬规则代码判定，输出风险提示卡片，无 LLM | 无 |
| **A2-3** | **恶意行为检测 Tool（LLM 语义层）** | 工具第二层：语义恶意检测 + 校验硬规则结果，综合评分输出风险等级 | A2-2 |
| **A2-4** | **流程编排重构** | 5 层漏斗重构（规则→恶意→客户价值→判例→综合决策），异步并发设计，清除旧逻辑 | A2-1, A2-3 |
| **A2-5** | **置信度与胜率计算重塑** | 重新设计计算公式，基于规则匹配强度 + 风险等级 + 证据质量综合量化 | A2-4 |
| **A2-6** | **商家可配置参数入口** | 出厂默认值设计：评分分档阈值、恶意检测阈值可配置，接口预留 | A2-1, A2-2 |
| **A2-7** | **前端输出结构更新** | `StrategyOutput` 结构更新：新增风险提示、客户价值提示、参考信息区折叠展示 | A2-4, A2-5 |

### Agent 3 升级模块

| # | 模块名称 | 核心改动 | 依赖 |
|---|---------|---------|------|
| **A3-1** | **话术生成逻辑重构** | 取消三基调多版本，改为单一推荐话术 + 动态基调，封装为 Tool | 无 |
| **A3-2** | **话术风格约束系统** | 禁用词/句式规则注入 Prompt，店主人设约束，情境温度动态调整 | A3-1 |
| **A3-3** | **三类特殊应对思想接入** | 商家有责 / 恶意买家 / 常规协商三条应对思想路径，由 Agent 2 特殊状态标记驱动 | A3-1, A2-7 |
| **A3-4** | **客户价值标记接入话术** | 老客户 / 高价值订单话术温度差异化，由 A2 客户价值触发标记驱动 | A3-1, A2-1 |
| **A3-5** | **输入接口对齐 Agent 2 输出** | `ScriptInput` 结构更新：对齐新 `StrategyOutput`，接收情绪标记、价值标记、特殊状态标记 | A3-1, A2-7 |

### 推荐执行顺序

A2-1 → A2-2 → A2-3 → A2-4 → A2-5 → A2-6 → A2-7 → A3-1 → A3-2 → A3-3 → A3-4 → A3-5
