补充设计修改：

1.商家自定义配置入口：默认出厂设置值，商家按需调整（配置内容可能包括客户价值评估机制、优惠福利、补偿机制等）

2.置信度、胜率计算重塑

3.客户价值评估（包装为tool）
  用户历史价值评估+本单价值评估
根据分开的多项评估指标分别为二者打分，分设阈值对用户分类

**设计原则**  
- **双维独立**：长期价值和本单价值分开计算，互不稀释。任一维度在高位，都不该被另一维度的低位掩盖。  
- **可解释**：每个维度的分数都有对应的评估依据，商家能看懂“为什么这个客户被优待”或“为什么这次建议多补偿”。  
- **可配置**：各指标的分档和阈值作为出厂默认值，商家可在后台按自己店铺的客单价、品类、毛利空间自行调节。

**长期价值分**  
反映买家在本店的长期关系价值，评估维度包括：  
- 累计消费金额：衡量整体贡献  
- 累计订单数：衡量购买频次  
- 最近购买时间：衡量活跃度和黏性  
- 历史纠纷率：衡量合作顺畅程度  
- 好评/带图评价记录：衡量正向反馈意愿  

每个维度按经验预设若干分档，五项之和为长期价值分。得分越高，说明买家越值得长期维护。

**本单价值分**  
反映当前纠纷中的处理价值与难度，评估维度包括：  
- 本单金额：订单本身的价值大小  
- 售后问题严重性：瑕疵程度和影响使用程度  
- 商品可挽回性：退货后能否二次销售或修复  
- 买家配合度：是否积极举证、态度是否理性  
- 诉求合理性：要求退款/补偿的金额和方式是否在合理范围内  

每个维度同样分档评分，五项之和为本单价值分。得分越高，说明本次纠纷值得投入更多精力去妥善解决。

**触发逻辑**  
- 长期价值分高于预设线 → 启动“长期客户优待”，话术偏暖，维护长期客户。  
- 本单价值分高于预设线 → 启动“本单重点处理”，快速响应，妥善处理。
- 两者均低于预设线 → 按默认规则处理，不加额外优待。  

分类结果只影响补偿力度和话术风格，不改变基于事实和规则的判责结论。

**工具输入**  
- 买家画像数据：累计消费、订单数、最近购买时间、纠纷率、好评记录（画像部分暂时无接入，保留调用入口）
- 当前订单数据 
- Agent 1 事实输出：瑕疵类型、严重程度、商品状态  
- Agent 4 情绪输出与聊天行为：配合度、态度  

**工具输出**  
- 长期价值分及其分项明细  
- 本单价值分及其分项明细  
- 触发标记：长期通道 / 本单通道 / 无触发  
- 优待建议：若触发，给出补偿上限提升幅度和话术温度调整方向



4.恶意行为检测（包装为tool）

**定位**

独立工具，供 Agent 2 决策漏斗第二层调用。内部按“先硬规则、后语义分析”两层运行，逐项检测可能的恶意行为，输出结构化风险评估卡供综合决策层使用。

**设计原则**

- **硬规则优先**：能用数据直接判定的行为，绝不让模型猜。
- **量化可解释**：每条风险信号有明确触发依据，商家能看懂，平台能对质。
- **纯函数无状态**：不直接访问数据库，所有数据由 Agent 2 传入。
- **可配置阈值**：退货率异常线、关联账号数等参数作为出厂默认值，商家后台可调。

**检测结构：分层运行，逐项排查，层间融合**

**第一层：硬规则匹配（代码执行，无 LLM）**  
对可量化的恶意行为设置明确的触发条件，命中即记录风险信号及其分值。规则之间互不干扰，可同时命中多项。输出为结构化的“风险提示卡片”，仅包含已触发的异常项。

检测项（未接入平台接口的部分保留数据查询接口）：

- 虚假凭证骗退款：买家上传图片经多模态分析判定为网图、同图或信息不完整、证据质量过低且申请仅退款。
- 滥用仅退款：退货率显著异常、近期仅退款次数明显偏高、订单金额集中在平台补贴区间。
- 批量恶意下单：近期下单频繁但付款率低、多笔订单收货地址相同、注册时间短但购买行为集中。
- 骗取运费险：退货率远高于类目均值且退货订单中运费险使用率偏高。
- 退货调包与少件：历史被多次标记为调包或少件、退货包裹重量与寄出时明显不符。
- 退货地址异常：退货地址与收货地址不一致且无合理解释、或频繁拒收导致物流异常。
- 关联账户异常：同地址或同设备关联多个账号、多账号交替下单、账号注册时间集中。

**第一层输出示例（风险提示卡片）**
- 滥用仅退款：近30天退货率92%，类目均值16%，触发高风险标记。
- 关联账户异常：同一收货地址关联3个以上买家账号，均在30天内注册。

**第二层：LLM 语义分析（融入硬规则提示）**  
LLM 接收到第一层产出的风险提示卡片、聊天记录、Agent 1 关键事实以及买家画像数据。在分析过程需要完成以下两个任务：

1. **语义恶意检测**：识别对话中可能存在的恶意意图，包括但不限于：
   - 差评与投诉勒索：以差评、12315、平台曝光等为要挟索要赔偿。
   - 冒充身份施压：冒充平台官方、执法机构或第三方鉴定人员。
   - 话术与证据矛盾：口头描述与上传图片（经 Agent 1 分析）明显不一致，或前后说法自相矛盾。
   - 职业索赔话术特征：大量使用规则术语、格式化话术，明显非普通消费者表达方式。

2. **校验第一层判断**：对照风险提示卡片，在聊天记录中查找与第一层输出提示相关证据，例如：
   - 卡片提示“滥用仅退款”，聊天中出现“这次跟上次一样，退了就行了”。
   - 卡片提示“关联账户异常”，聊天中无意提及“我那个号买的另外一件也这样”

**量化评估**

汇总两层信号，计算综合风险评分。每条硬规则命中计固定分值，每条语义风险信号按强度，最终映射为风险等级。

**输出结构**

- 综合风险评分：反映整体恶意可能性。
- 风险等级：低、中、高。
- 风险信号明细：每条信号的描述。
- 处置建议：低风险正常处理，中风险谨慎协商并加强举证要求，高风险建议抗辩并引导平台介入。

**工具输入**

- 买家画像数据：退货率、纠纷次数、恶意标记计数、购买频次、账号注册时间。（未接入平台接口的部分保留数据查询接口）
- 订单信息：本单金额、收货地址、设备指纹、近期订单列表。
- Agent 1 事实输出：瑕疵类型、证据质量、图片分析结果、物流状态。
- 聊天记录摘要与 Agent 4 情绪输出：用于语义层的威胁检测和矛盾分析。

**工具输出**

- 综合风险评分及等级。
- 风险信号明细列表。
- 处置建议方向。
- 该输出直接传给 Agent 2 的综合决策层，无需做二次规则匹配。

**与 Agent 2 的接口**

- 若风险等级为高，综合决策层显著倾向抗辩，即使规则层面存在协商可能。
- 若风险等级为中，协商策略中加强举证要求并降低补偿上限。
- 若风险等级为低，不干预后续决策方向，继续走客户价值评估和判例参考。

恶意行为分类与示例：

一、利用平台规则漏洞获利
滥用“仅退款”：无合理理由申请退款不退货
虚假凭证：上传PS图片、网图、同图等伪造证据
骗取运费险：通过刷单或恶意退货赚取运费赔付差价
恶意差价退款：故意虚构瑕疵要求退款，实际商品完好
知假买假索赔：以“打假”为名索要高额赔偿

二、退货欺诈
退货调包：退回空包、旧物、仿品等不同商品
买真退假：购买真品后，同款假货退回
退货少件：故意少退部分商品但申请全额退款
恶意拒收：无故拒收正常商品，逃避运费

三、恶意攻击店铺运营
批量恶意下单：大量拍下商品不付或秒退，占用库存
差评勒索：差评威胁索要钱财或好处
恶意“炸店”：有组织地集体攻击某店铺，批量下单后集体差评退款
投诉勒索：放大商家瑕疵，以投诉为要挟索财

四、有组织的黑灰产
多账号薅羊毛：注册大量账号，利用新人优惠、补贴套利
职业索赔团：分工明确、批量下单、统一模板投诉索赔
骗取平台补贴：虚假交易套取平台红包、优惠券
