# 产品需求文档 — 商家应诉助手

## 项目背景

电商中小商家处理售后纠纷时，常因不熟悉平台规则、不懂有效举证、情绪化决策导致不必要损失。每次纠纷处理经验也无法沉淀复用。

## 目标用户

- 淘宝/拼多多/抖音等平台的中小商家
- 日均订单 10-100 单，无专业客服团队
- 每月纠纷量 10-50 起，客单价 50-500 元

## 产品定位

商家的“理性外脑”：帮助商家看清局势、控制情绪、做出长期利益最大化的决策。
产品提供两种运行模式，商家可根据自身情况自由切换。

## 核心功能

1. **纠纷事实提取**：自动分析买家举证（文字、图片、物流），输出结构化事实和疑点。
2. **策略建议**：结合平台规则、买家画像、历史判例，给出抗辩/协商/体面善后建议及预估胜率。
3. **多版本话术生成**：生成多种风格回复话术供商家选择或系统自动发送。
4. **情绪监控**：辅助模式下监控买家情绪和商家非理性操作，智能模式下评估买家情绪调整策略。
5. **复盘沉淀**：纠纷结束后自动提炼经验，存入私有判例库。

## 模式一：辅助模式

人工主导，AI 辅助。AI 只在商家主动请求时提供信息和建议帮助判断，商家始终掌控消息发送权。

### 交互方式

- 左右分栏布局：左侧聊天窗口，右侧 AI 策略面板。
- 侧边栏展示事实摘要、策略建议、多版本话术、用户画像、情绪识别等

### 业务流程

1. 买家发起售后纠纷。
2. 商家点击「AI助手」。
3. 系统拉取全部已有材料，调用 Agent 1→2→3 全链路分析。
4. 侧边栏展示分析报告和多版本话术，Agent 4 实时监控商家操作情绪。
5. 商家选择话术手动发送。
6. 买家回复后，商家按需自行点击「AI助手」调取AI支持。
7. 重复直至纠纷关闭。
8. Agent 5 异步生成复盘经验卡片。

### 适用场景

- 商家希望完全掌控对话节奏。
- 纠纷复杂，需要人工判断买家意图。
- 高客单价订单，谨慎处理。

## 模式二：智能模式

AI 主导对话，人工兜底。对外表现为一个智能客服，能自主接收买家消息、按需调动内部 Agent 完成对话。仅在无法处理或商家主动接管时，总结生成当前局势的移交摘要，切换回辅助模式由商家接手。

### 交互方式

- 自动化仪表盘布局：展示对话状态、置信度、当前策略等。
- 商家可随时点击「接管」暂停 AI，切换回辅助模式。

### 适用场景

- 商家同时处理多个纠纷，希望批量自动化。
- 低客单价标准化纠纷，人工处理 ROI 低。
- 商家已建立对 AI 建议的信任，愿意让 AI 执行。

## 模式切换

- 商家在设置页自由切换辅助模式与智能模式。
- 切换时后端更换控制器，前端更换界面布局。
- 智能模式下商家可随时点击「接管」回到辅助模式。
- 两种模式共享同一套 Agent 核心代码。
