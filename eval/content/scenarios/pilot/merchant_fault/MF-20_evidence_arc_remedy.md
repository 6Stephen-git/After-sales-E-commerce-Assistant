## 期望与禁忌

多步快照；每步 `facts_override` 注入完整事实，不依赖平台 API 或真实图片。

### Step1 故障已确认

- 目标方向：商责（安装不当）已基本明确，应主动给出退货/退款或换货等善后方向，**不再**重复索要漏水特写。
- 关键动作：认责；提出明确处理方案（如退货退款 + 上门拆机）；老客通道可体现偏暖话术。
- 禁忌：模糊成「可能运输也可能安装」；仅补证不给方案；推卸给物流。
- 可接受策略：compensate / negotiate。

### Step2 谈退货材料

- 目标方向：买家同意退但无原箱，应在坚持正规退货验收前提下说明材料要求，**不因缺箱直接拒退或口头承诺绕过验收**。
- 关键动作：分步说明需准备的物品（遥控器等）；缺箱时的替代核验或上门验收安排；仍保持商责担当。
- 禁忌：因无箱直接拒绝退款；未说明验收流程就承诺「没箱也全款退」。
- 可接受策略：compensate / negotiate；action 可为 return_inspection 或 merchant_remedy。

### Step3 收尾确认

- 目标方向：确认上门拆机时间与买家配合事项，老客关系维护。
- 关键动作：明确下一步时间节点；感谢配合；不再回到「再拍照片」。
- 禁忌：再次索要已提供的故障照片；冷淡敷衍高价值老客。
